# SMS Ledger

A smart Android financial tracking application that automatically parses bank transaction SMS messages, categorizes expenses, displays balance breakdowns, and manages custom transaction categories.

## 🚀 Key Features

- **Automated SMS Parsing**: Reads incoming and historical bank SMS notifications to detect debits, credits, account numbers, and merchant names.
- **Unified Persistent Signing Key**: Built and signed with a persistent keystore so that all future app releases update seamlessly over your existing installation without losing local data.
- **Instant Permission Handling**: Prompts for SMS and Notification permissions on first launch and includes a dashboard action banner if permissions need to be granted.
- **Custom Categories & Rules**: Add custom category rules that automatically organize your transactions.
- **Rich Notifications**: Interactive custom notification layouts for real-time transaction alerts.

## 🛠️ Installation & Play Protect Guide

1. Download `sms_ledger.apk` from the link above.
2. Tap the downloaded APK to install.
3. **Google Play Protect Notice**:
   - Because this app is sideloaded outside Google Play and requests SMS reading permissions, Google Play Protect may display a warning (*"Unrecognized app"*).
   - Tap **"More details"** and then **"Install anyway"**.
4. Launch the app and grant **SMS permission** when prompted to automatically load your accounts and transaction history.
